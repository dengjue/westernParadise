## 一句话现状

参考作品是一个 **2.87 MB 的单文件 HTML**，内含完整 Three.js 引擎 + 一款 FPS 游戏，
**零远程资源、断网可玩**。它其实是一个 **36 个模块的原始工程**被打包内联后的交付产物，
且注释几乎完整保留 —— 因此它同时是一份可读的**架构说明书**。

**但不要直接改它**：标识符已混淆（`gf` / `M2` / `oi` / `en`）、无 source map、最长单行 23.8 万字符。
正确用法是把它当**规格书**，抽取可复用的设计，重新生成可读代码。

## 复跑分析脚本

```bash
cd "/Users/dj/文件/网上寺庙/03-工具"
python3 scan_single_html.py                      # 默认分析 00-原文件 下的 HTML
python3 scan_single_html.py --input /路径/其他.html --output-dir /路径/输出
python3 scan_single_html.py --extract-css --extract-js   # 同时导出内联 CSS / JS
```

纯静态分析，不执行 HTML 里的 JS、不联网，仅 Python 3.9+ 标准库。

## 口径与不确定性（重要）

本工作区所有结论来自**静态文本扫描**，不是运行时抓包。请留意三处口径：

| 项 | 数值 | 口径 |
|---|---|---|
| 原始工程模块 | **36 个** | 脚本按 `\d{2}-xxx.js` / 路径形式还原的**有效文件名** |
| 早前口头提到的 38 个 | 38 | 含 `Three.js`、`three.js` 两处**库名引用**，不是模块文件 |
| 中文字符串 | **1864 条** | 正则抽取的所有含中文的引号字符串去重，**含注释片段与模板串，有噪声** |
| 场景/UI 文案 | 约 726 条 | 人工筛选后的短文案（<30 字），才适合当文案参考 |
| 网络 API 命中 | `fetch(` ×3 等 | **命中 ≠ 发起请求**，三处均为 Three.js Loader 类定义，需逐个看上下文 |

结论口径：**"零远程资源"是静态证据下的强结论**（无 link/img/外链 script、无 CSS url/@import/@font-face、
唯一 `http://` 是 `createElementNS` 命名空间常量）；若需 100% 坐实，请用 DevTools Network 面板或断网实测再验一次。
