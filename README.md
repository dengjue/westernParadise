# 西方极乐世界 · 数字园境共创

> 一起搭建一个可以漫游、持续生长的数字园境。欢迎对 3D、建筑与园林、交互、声音、性能、测试或文档感兴趣的伙伴参与。

这是一个以理想园林与建筑空间为灵感的浏览器 3D 共创原型，当前重点是空间探索、建筑细节、光影变化与漫游体验。它还在持续建设中，不是已经完成或正式发布的产品。

## 一起建设什么

- **扩展世界**：探索更大尺度的园林、建筑群与空间分区。
- **打磨漫游**：完善第三人称步行、飞行、导航、移动端操作与可访问性。
- **创造氛围**：共同尝试建筑构件、材质、植物、光影、天气和自然声景。
- **做好工程**：优化渲染性能、离线体验、测试工具与开发文档。

欢迎先从体验反馈、问题复现、文档改进或小型 Pull Request 开始。暂时不知道从哪里下手，可以先看 [当前计划与待办](AGENT_TODO.md)，再通过 Issue 讨论想法。

## 当前原型

- 程序化构建的殿宇、园林、莲池、树木与空间细节。
- 第一人称漫游、观景点、自动游览、光阴变化与自然环境音。
- 第三人称步行及有界飞行/导航原型：在地址后添加 `?cam=third` 开启。
- 支持生成离线单文件；项目默认不依赖远程素材。

目前自动化基线为 **30 个测试文件、181 项用例**。第三人称操作手感仍待人工确认，真实手机持续性能与更严格的长帧验收也还在计划中；详见[长期工作计划](02-方案/19-长期工作计划-大世界第三人称与性能验收.md)。

## 本地运行

需要 Node.js ≥ 22 和 npm。克隆仓库后运行：

```bash
npm ci
npm run dev
```

开发服务器启动后，按终端提示打开本地地址。第三人称原型可在地址后加 `?cam=third`。

常用检查与构建：

```bash
npm run verify          # 类型检查、架构/文案门禁、测试及双产物构建
npm run build:single    # 生成离线单文件
```

单文件产物位于 `dist/single/index.html`，只用于本地验证；当前没有已部署的在线体验。

## 如何参与

1. 在 Issue 中描述想法、问题或设备环境；新功能建议先讨论范围。
2. 开始修改前阅读 [`AGENT.md`](AGENT.md) 和 [`AGENT_TODO.md`](AGENT_TODO.md)，遵守项目的架构、内容、版权与质量要求。
3. 尽量让改动小而清晰，并说明验证方式；提交前运行 `npm run verify`。
4. 通过 Pull Request 分享改动与测试结果。视觉或交互改动请附截图、录屏或复现步骤。

适合贡献的方向包括：第三人称操作体验、移动设备测试、性能分析、世界分区方案、无障碍与减动效、程序化建筑/园林表现，以及完善中文文档。
