# Western Paradise · 西方极乐

**一个可以自由漫游的传统建筑与园林 3D 世界。** 我们正在探索如何把建筑、空间、光影与环境声音做成轻量、可离线体验的数字漫游作品。

[GitHub 源码仓库](https://github.com/dengjue/westernParadise) · 公开协作入口暂未开放

> 这是一个实验性原型，不是宗教信息或宗教仪式服务，也不代表真实寺院或宗教组织。项目仍在探索和验收中，暂不作为正式产品发布；公开招募、公开体验和分发须等待合规评估与项目负责人批准。

## 项目进度

目前已有园林漫游、四个观景点、第一人称步行、自动游览、光影时段切换、四档画质、第三人称步行/飞行/导航及游线；第三人称模式含核心庭园和东侧水院灰盒与原型级 cell 调度。多人同图仍是受控局域网测试原型，入口不在公开页面列出。最近一次完整 `npm run verify`（2026-11-26）通过：**49 个测试文件、315 项测试**，类型/分层/内容检查、lint/格式、站点与离线单文件构建及单文件静态断言均通过；站点构建仍提示 Three.js chunk 超过 600 kB 的体积建议。单文件为 1,474,596 字节；静态断言不替代目标设备性能测试。

产品仍属原型：阶段 1/2 手感和东区灰盒构图待人工确认；阶段 4 分区加载与驻留预算未按目标设备校准；A4 严格桌面性能未通过，B0 手机持续性能和 C0 原生生命周期未关闭；其余七区尚未生成，阶段 5–6 未开始。公开发布闸门仍关闭。请以[长期工作计划](02-方案/19-长期工作计划-大世界第三人称与性能验收.md)和[产品交付评估](02-方案/27-产品交付状态评估与未完成项.md)为当前状态依据，具体证据见[性能与设备验收方案](02-方案/18-后续优化-性能收敛与真机验收.md)。

## 自动化验证

| 命令 | 用途 |
|---|---|
| `npm run test` | 运行自动化测试 |
| `npm run verify` | 运行完整检查与构建 |
| `npm run build` | 构建多文件站点到 `dist/site/` |
| `npm run build:single` | 构建离线单文件到 `dist/single/index.html` |

项目使用 TypeScript、Three.js、Vite 与 Vitest。源码在 `src/`，测试在 `tests/`；编号目录体现单向依赖层级。`dist/`、`reports/` 和 `node_modules/` 是本地产物，不提交到仓库。
