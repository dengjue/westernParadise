## 一句话现状

参考作品是一个 **2.87 MB 的单文件 HTML**，内含完整 Three.js 引擎 + 一款 FPS 游戏，
**零远程资源、断网可玩**。它其实是一个 **36 个模块的原始工程**被打包内联后的交付产物，
且注释几乎完整保留 —— 因此它同时是一份可读的**架构说明书**。

**不要直接改它**：标识符已混淆（`gf` / `M2` / `oi` / `en`）、无 source map、最长单行 23.8 万字符。
正确用法是把它当**规格书**，抽取可复用的设计，重新生成可读代码。

**当前进度**：阶段 0 资料沉淀、阶段 2.A 工程底座、阶段 2.B1~2.B6，以及阶段 3.1~3.4
（程序化庭院、斗拱意象、纸面屏风、铺装苔痕、可切换雨效与自然声床）已完成并通过 `npm run verify`；版本已升至 0.1.0。
仓库为工蜂私有。

## 工程化开发（路线 C）

环境要求：Node ≥ 22（见 `.nvmrc`）、npm。依赖锁在 `package-lock.json`。

```bash
npm ci                 # 首次 / CI 安装，严格按 lock 文件
npm run dev            # Vite 开发服务器，HMR
npm run verify         # 一条命令跑完所有门禁 + 两种构建（CI 复用同一命令）
```

| 命令 | 作用 |
|---|---|
| `npm run typecheck` | TypeScript `strict` 类型检查 |
| `npm run lint` / `format:check` | ESLint / Prettier 一致性 |
| `npm run test` | Vitest（13 文件 / 80 用例，纯 Node 环境） |
| `npm run check:layers` | 单向依赖、目录入口、浏览器 API 边界、循环依赖 |
| `npm run check:content` | 源码与文案的宗教红线词扫描（37 词） |
| `npm run build` | `dist/site/` 多文件站点产物 |
| `npm run build:single` | `dist/single/index.html` 全内联离线产物 |
| `npm run verify:single` | 产物零外链断言 + 体积/MD5 报告 |

**架构要点**：编号即依赖等级，只能依赖更低的层；跨层只能引用目录入口；
`window` / `document` / `localStorage` 被隔离在 `03-platform`、`08-ui`、`98-diagnostics`、`99-boot`，
核心层因此可在 Node 里直接测。详见 `02-方案/04-工程化架构设计.md` 第 2 节。

**双产物**：`dist/site/` 供将来部署；`dist/single/index.html` 供断网双击、微信转发。
2026-11-12 实测单文件 **605,274 字节（0.577 MiB）**，约为参考件的 20%。
`dist/`、`reports/`、`node_modules/` 均不入库。

**调试参数**：`?q=low|medium|high|ultra`、`?seed=`、`?bench`、`?smoke`、`?debug`、`?noaudio`。
`?debug` / `?smoke` 下才挂 `window.__G`，生产单文件不暴露内部对象。

## 口径与不确定性（重要）

**阶段 0 的结论**全部来自**静态文本扫描**，不是运行时抓包。请留意三处口径：

| 项 | 数值 | 口径 |
|---|---|---|
| 原始工程模块 | **36 个** | 脚本按 `\d{2}-xxx.js` / 路径形式还原的**有效文件名** |
| 早前口头提到的 38 个 | 38 | 含 `Three.js`、`three.js` 两处**库名引用**，不是模块文件 |
| 中文字符串 | **1864 条** | 正则抽取的所有含中文的引号字符串去重，**含注释片段与模板串，有噪声** |
| 场景/UI 文案 | 约 726 条 | 人工筛选后的短文案（<30 字），才适合当文案参考 |
| 网络 API 命中 | `fetch(` ×3 等 | **命中 ≠ 发起请求**，三处均为 Three.js Loader 类定义，需逐个看上下文 |

结论口径：**「零远程资源」是静态证据下的强结论**（无 link/img/外链 script、无 CSS url/@import/@font-face、
唯一 `http://` 是 `createElementNS` 命名空间常量）；若需 100% 坐实，请用 DevTools Network 面板或断网实测再验一次。

**阶段 2.A 的边界**：`npm run verify` 全绿只证明类型、分层、测试、构建与**产物静态零外链**。
`dist/single/index.html` 的**断网实玩、像素正确性、移动端与帧率**仍属人工验收，尚未执行；
触控输入仍只保留接口，静态扫描不冒充运行时实测；2.B4~2.B6 的桌面开发页走查已完成，
见实施规范第 5~8 节。断网双击与 Network 复核仍需在目标交付环境复跑。
