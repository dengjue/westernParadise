**结论**：把这段录屏原貌 + 「网上寺庙 / 心灵净土 / 一起共修」这类文案直接发到抖音、小红书，同时做公开招募，落在项目自己定义的高风险区（公开传播 + 面向不特定公众 + 宗教文化信息 + 引流）。这不是能不能过审的运气问题，是口径问题。**脚本不能照这个写。**

### 0.2 两条路线（推荐 A）

| | 路线 A · 收敛口径（本脚本采用） | 路线 B · 原貌展示 |
|---|---|---|
| 对外定位 | 传统建筑与园林的**数字漫游 / 开源技术协作** | 现有「极乐世界」题材原貌 |
| 画面 | 录屏只取远景、莲池、阶道、长廊；裁掉 UI 与宗教题名；**不出现造像与匾额** | 录屏原片直接剪 |
| 文案 | 不出现寺庙/净土/极乐/修行/功德/祈福；「静心」改写成「慢下来、歇一会儿」 | 用户原始表达 |
| 招募 | 招募**共建者**（体验反馈 / 美术 / 声音 / 前端 / 测试 / 文案），指向评论区承接，不挂外链二维码 | 同左 |
| 前置条件 | 按 A 轨完成素材与文案自检后即可发 | **必须先解锁** `08-对外发布合规送审包.md` 第 5 节闸门（书面法律意见 / 必要时许可 / 内容删改 / 负责人确认） |
| 状态 | ✅ 可执行 | ⛔ 暂缓 |

> 路线 A 也不是"绝对安全"的承诺：题材观感是否构成宗教文化信息，项目文档自己写明必须由外部专业人士定性。A 轨是**把风险降到最低的可执行口径**，不是法律结论。

### 0.3 A 轨的三条硬约束（写进每一句文案）

1. **用未来时说愿景**：「想把它做成打开浏览器就能走进去的地方」，不说「已上线 / 现在就能玩」。
2. **用建筑词说话**：庭院、殿宇、回廊、莲池、阶道、屋檐、光影、铺装 —— 只用空间与构件名。
3. **只招人不收钱、不引流现实场所**：不出现募捐/功德/香火/供灯/祈福，不放外链、不放二维码、不提真实寺院或宗教组织；站外承接走评论区 → 私信。

> ⚠️ **v0.3 口径调整（用户明确要求）**：为了强调「邀请共建这个世界」，视频内现在显示仓库名 `dengjue / westernParadise` 与一张 GitHub 仓库页实截；**仍无可点击链接、无二维码**，完整地址只放在评论区置顶。这属于站外引导信号，可能触发平台限流；且观众进入仓库后会看到含宗教文化信息的 README —— 收敛口径只覆盖视频本身，不覆盖站外落地页。详见第 11 节。

## 1. 这支片子要完成什么

| 项 | 定稿 |
|---|---|
| 目标人群 | 会被「一个人在做一座数字园林」打动的人：独立开发者、Three.js / 前端、3D 美术、国风建筑爱好者、音效设计、爱提体验反馈的普通用户 |
| 唯一动作 | **评论区留一句「我会什么」**，从而进入协作名单 |
| 不做什么 | 不介绍宗教、不讲教义、不展示仪式、不募捐、不宣称在线可玩、不堆技术参数、不喊口号 |
| 一句话主张 | **「一座还没建完的数字园林，想找人一起建。」** |
| 情绪曲线 | 疲惫 → 安静 → 好奇 → 坦诚 → 热闹（人多起来）→ 期待 → 邀请 |
| 叙事逻辑 | 先给一个情绪出口（忙），再给一个可看的东西（画面），然后**立刻坦白"做不完"** —— 招募的可信度来自坦诚，不来自宏大 |

> 关键判断：招募类视频最忌「看我多厉害」，最有效的是「这事还没成，缺你一个」。所以第 4 幕的坦白是全片转折点，不能省。

## 4. SVG 动画编排（分镜表）

### 4.1 视觉系统（token，实现时集中成常量表，禁止散落硬编码）

| 类别 | 值 |
|---|---|
| 底色 | 宣纸白 `#F5F2EA` → 米灰 `#E8E4D9` 竖向渐变 |
| 主墨色 | `#2E322F`（文字/线条） |
| 苔绿 | `#4C6B52`（屋檐、树影） |
| 水色 | `#A8C3C0`（莲池、光晕） |
| 点缀金 | `#B08D57`（细线、节点，面积 ≤ 3%） |
| 弱化 | 主墨色 40% / 24% 两级透明度 |
| 字体 | 标题：思源宋体 / Noto Serif SC **Light**，字距 `0.12em`；正文/字幕：思源黑体 / PingFang SC；数字：等宽 |
| 缓动 | `cubic-bezier(0.22, 0.61, 0.36, 1)`；单元素动效 600–1200ms |
| 禁止 | 弹跳、旋转、闪白、故障风、快速转场、粒子爆发、镜头抖动（`prefers-reduced-motion` 下全部降为静态） |
| 节奏原则 | **慢、少、留白**。每幕最多 2 组动效同时运行；任何时刻画面动的元素 ≤ 3 类 |

### 4.2 图层栈（从下到上，全程固定）

```
L0  纸纹底（SVG filter: feTurbulence 低强度，静态，不逐帧变化）
L1  SVG 背景动效（墨点 / 屋檐线 / 圆相 / 网格 / 光晕）
L2  录屏窗口（960×600，圆角 24，柔和投影，四边 40px 羽化渐隐）
L3  SVG 前景遮罩（左侧渐隐、墨晕转场、边框细线）
L4  主文字（一句主张）
L5  字幕（口播同步）
L6  角标 / 进度点 / 名单标签
```

### 4.3 逐幕分镜

| 幕 | 时间 | SVG 元素 | 动效编排 | 与录屏的关系 |
|---|---|---|---|---|
| **M1** | 00–06 | 满屏纸底 + 12 个密集小墨点（象征消息/待办）+ 一圈未闭合的圆相 | 墨点 0–1.8s 从四周向中心快速聚拢并轻微抖动；1.8–3.5s **减速、散开、变淡**；圆相 3.5–6s 一笔缓慢画完（stroke-dasharray） | 无录屏。纯 SVG，建立"静"的基准 |
| **M2** | 06–13 | 屋檐轮廓（贝塞尔双曲线）+ 柱列细线 ×7 + 阶道透视线 + 莲叶路径 ×5 + 一枚暖光晕 | 全部用 `stroke-dashoffset` 按 06.2 / 07.4 / 08.6 / 09.8s **依次"长出来"**，各 900ms；光晕 09–13s 缓慢右移 120px（对应"会移动的光"） | 无录屏。用线条把"园林"从纸上生成，为录屏出场做铺垫 |

| **M4** | 24–33 | 蓝图网格（24×24 淡线）+ 节点网络：已亮 5 个 / 空缺 9 个（虚线空心圆） | 24s 录屏淡出 300ms，网格浮现；28s 起空缺节点**逐个轻微脉冲**一次（不闪），停住不填 —— 视觉上就是"缺人" | 录屏退出。全片最重要的图形隐喻 |
| **M5** | 33–45 | 同上网格 + 6 枚标签胶囊（体验 / 美术 / 声音 / 前端 / 测试 / 文案）+ 细连接线 | 33s 录屏段② 从网格中央淡入；35–43s 六枚标签**自下向上错峰淡入**（间隔 300ms），连接线同步生长；空缺节点被标签"点亮"3 个，其余仍空（诚实：还在招） | **录屏段② 作背景层**（降饱和 15% + 压暗 10%），文字/网格为前景 |

## 5. 录屏嵌入节点（精确秒数 + 处理规范）

> ⚠️ **v0.2 修订**：本节下方记录的源片秒数与裁切参数是初版判断，经逐帧实测已证实有误（详见第 10 节）。**实际执行以第 10 节为准**，本节仅保留决策留痕。

### 5.1 逐帧核对结论

| 时间段（源片） | 画面 | 风险 | 判定 |
|---|---|---|---|
| 00:00–00:10 | 高空俯瞰全景，左侧「西方极乐」大字最清晰 | 高 | ❌ 禁用 |

## 7. BGM 编排

### 7.1 选曲方向与禁区

| 项 | 定稿 |
|---|---|
| 方向 | 极简钢琴单音 + 低音量环境垫（弦乐 / 空气感 pad）；可加极轻的水声、风声 |
| 速度 | BPM 60–72，**无鼓点或仅每 2 拍一次极轻脉冲** |
| 调性 | 平和、无强解决感；避免大起大落的副歌结构 |
| **禁区** | 梵呗、唱念、木鱼、钟磬、诵经、法会录音、任何带宗教指向的人声采样 —— 项目红线 `03-风险与合规红线.md` 3.2 明确「不使用诵经、法会、唱念音频」 |
| 版权 | 只用平台商用曲库 / 免版税可商用来源（保留授权凭证）；**不用流行歌曲**。录屏源片无音轨，BGM 需独立铺满全程 |
| 纯字幕版 | 若最终不做口播，BGM 整体 +2dB，M4/M5 补一层极轻的低频脉冲维持推进感 |

### 7.2 情绪曲线与卡点表

| 时间 | 音乐层 | 动作 | 对应画面 |
|---|---|---|---|
| 00–06 | 单音钢琴（每 2 秒 1 音）+ −26dB 纸面底噪 | 起，音量 −18dB | M1 墨点聚拢→散开 |
| 06–13 | 加入极淡 pad | 13.0s **换气点**，短暂停 0.3s | M2 线条生长 → 录屏 Reveal |
| 13–24 | pad 铺开 + 水声，音量升至 −12dB | 15s 起缓慢渐强 | M3 段① 录屏 |
| 24–33 | 撤掉水声，只剩钢琴 + 薄 pad | 24.0s 收一层；28.0s「一个人，建不完」处**留一拍空白** | M4 坦白 |
| 33–45 | 加轻脉冲（每 2 拍一次），逐步加入第二声部 | 33.0s 第一个脉冲 = 招募启动；38.0s 标签首现再抬 1dB | M5 段② + 六类标签 |
| 45–54 | 全曲最满（三层），但不加鼓 | 45.0s lift；52.0s 开始回落 | M6 愿景扩散 |
| 54–60 | 回到单音钢琴，撤掉所有垫 | 58.0s 只留尾音，60.0s 前 1.5s 自然衰减 | M7 静止收尾 |

**旁白 ducking**：口播出现期间 BGM −6 ~ −9dB，前后各 200ms 平滑过渡；留白段恢复。母版输出 −14 LUFS（抖音）/ −16 LUFS（小红书）各导一版，峰值 ≤ −1dBTP。

## 10. 实现记录与实测修正（2026-11-16 · v0.2）

### 10.1 三个必须记录的实测发现

| # | 发现 | 影响 |
|---|---|---|
| 1 | **输入侧 `-ss` 快速 seek 会偏移**。源片 120fps 且时间戳不连续，按时间戳 seek 与按帧序号取样落在不同镜头上，偏差可达数十秒 | 初版基于 `-ss` 单帧缩略图得出的可用区间全部作废；改为「从头解码 + `fps` 取样 / `trim`」复核 |
| 2 | **源 00:29–00:39 推近主殿后，「无量光殿」匾额与三尊金色造像清晰可辨** | 初版指定为段②，**已弃用** |
| 3 | **源 00:44–00:54 同样含主殿正面造像 + 「西方极乐」大字** | 备选段也弃用；全片大部分镜头都含主殿或题名，不能靠"选一段"解决 |

### 10.2 最终采用的方案：改裁切框，而不是靠遮盖

| 段 | 成片位置 | 源片区间 | 裁切框（源 3188×1982） | 画面内容 | 复核结果 |
|---|---|---|---|---|---|
| **①** | 13–23s | **60.0–70.0** | `crop=1296:810:200:950` → 960×600 | 莲池、莲花、树、阶道与铺装俯瞰 | ✅ 无造像、无匾额、无题名、无 UI |
| **②** | 33–43s | **36.0–41.0**，`setpts=2*PTS` 慢放 2 倍 | `crop=2528:1580:200:160` → 960×600 | 长廊栏杆、树、铺装近景 | ✅ 完全干净 |

- 段① 的新裁切框**只取画面下半部**，从几何上把殿内造像（约源 y=690–900）排除在窗口之外，而不是用雾罩打码。
- 段② 只有 5 秒素材，用源片 120fps 的优势慢放 2 倍到 10 秒，输出 30fps 仍有充足独立帧，且更贴合「慢慢走」的调性。
- 两段都去掉了顶栏「极乐世界 / 四景点名」、底部控件与右侧设置面板；左侧残留的「西方极乐」大字由 19% 宽的宣纸渐隐层吃掉（同时形成「画面从纸里浮出」的视觉语言）。
- 录屏层另加 `blur(.6px) saturate(.94)` 与顶部柔雾，弱化远景细节。**残留**：画面里有很小的鼠标指针；属演示录屏的正常痕迹，不影响内容定性。

### 10.4 实现口径

- **单一真实来源**：`preview.html` 既是预览母版，也是导出用的渲染源；30s 版通过时间映射表复用同一母版，不维护两套动画。
- **确定性渲染**：所有动效由 JS 按绝对时间求值（不用 CSS keyframes），录屏用帧序列而非 `<video>`，CDP 逐帧截图结果可复现。
- **配置集中**：尺寸、时间轴、文案、素材路径全部在 `CFG` / `MAIN_TEXT` / `CAPTIONS` / `LABELS` 常量表，渲染逻辑不散落硬编码。
- **降级**：`prefers-reduced-motion` 语义下动效可静态化；静音按钮、播放/暂停/拖动时间轴齐备。
- **v0.3 证据幕**：`preview.html` 新增 `#shotBox` 图层与 `CFG.SHOT` 配置，截图作为单张图片纳入 `__ready` 就绪判定，逐帧渲染仍然确定。
