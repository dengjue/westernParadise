- 主推 8.5MB：本地 libx264 两遍、1152×716@30fps、720kbps、H.264 High / yuv420p / faststart。HQ 29MB：qu0 RTX 3070 `h264_nvenc -preset p7 -rc vbr -b:v 2500k`、1600×994@30fps。
- 结论：NVENC 赢在速度（18s vs x264 43s），不赢在低码率画质——同 700kbps 下雾面出色块、顶部小字糊掉，x264 两遍明显更干净；NVENC 恒定质量 `-cq 23` 会飙到 6.2Mbps/74MB，不适合"压小文件"目标。以后录屏压小文件优先本地 x264 两遍，GPU 只用于快速出高码率版本。
- GitHub README 放视频规则：免费版仓库视频附件上限 **10MB**（付费 100MB），官方推荐 H.264；把 mp4 拖进 GitHub 网页编辑器/issue 得到 `https://github.com/user-attachments/assets/<uuid>`，把该 URL **单独放一行**（上下空行）才会自动渲染播放器；手写 `<video>` 标签/YouTube iframe 不可靠，页面 CSP 会拦截外部 CDN 与自建域名的媒体地址。YouTube/B站只能做"封面图 + 链接"。
