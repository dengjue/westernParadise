> 注意：全文件搜 `url(` 会命中 9 处，但都在**压缩后的 JS 代码**里（如 `url(` 出现在字符串或 `new Blob([hand4WorkerSource(...)])` 附近），
> 不是 CSS 资源引用。**限定 `<style>` 块内统计为 0**，这才是正确口径。

### 2.2 唯一的 http 字符串

全文仅 1 个真实 `http://` 字面量：

```
http://www.w3.org/1999/xhtml
```

上下文：

```js
function Zl(i) { return document.createElementNS("http://www.w3.org/1999/xhtml", i) }
```

这是 `document.createElementNS()` 的 **XML 命名空间常量**（Three.js 用来创建 canvas 元素），
**不是网址、不产生任何网络请求**。这是判断"零远程"时最容易误报的一处，务必说清。

### 2.3 协议相对 URL 与可疑字符串

全文扫出的 `//host` 形态 2 条，均为**正则源码字符串**，不是请求：

```
//i.test(t)&&/^\//.test(e)&&(t=t.replace(/(^https?:\/\/[^\/]+).*/i,
//i.test(e)||/^data:.*,.*$/i.test(e)||/^blob:.*$/i.test(e)?e:t+e)}},ea=class
```

字符串字面量中「看起来像 URL」的 6 条，逐条定性：

| 字符串 | 定性 |
|---|---|
| `http://www.w3.org/1999/xhtml` | XML 命名空间常量，无害 |
| `:/^https?:\/\//i.test(t)...` | Three.js Loader 的 URL 处理正则，类定义 |
| `),/^(https?:)?\/\//i.test(e)...` | 同上 |
| `// SALTLINE_SHADOW` | GLSL 着色器片段标记 |
| `// cubeToUV()` | Three.js 内部注释 |
| `// SALTLINE_POST` | GLSL 后处理标记 |

### 2.4 网络 API：命中 ≠ 调用

| API | 命中次数 | 逐条定性 |
|---|---:|---|
| `fetch(` | 3 | **全部是 Three.js Loader 类的定义代码**：`FileLoader`（处理 http status 0）、`ImageBitmapLoader`（能力检测 + `createImageBitmap`）、以及 `fetch(e,a).then(...blob())`。游戏本身**未实例化这些 Loader 去加载任何 URL** |
| `XMLHttpRequest` | 0 | — |
| `WebSocket` / `EventSource` / `sendBeacon` | 0 | — |
| `importScripts` | 0 | — |
| `new URL(` | 0 | — |
| `new URLSearchParams(location.search)` | 2 | 读**本地地址栏参数**，不联网 |
| `location.hash` | 1 | 读 `#bench`，不联网 |
| `URL.createObjectURL` | 1 | 生成**本地 Blob URL** 给内联 Worker，不联网 |
| `navigator.*` | 6 | UA 判定、`OffscreenCanvas` 能力检测，不联网 |
| `localStorage` | 2 | 本地存画质/FOV 设置，不联网 |

**关键判据**：全文件 31 处 `load(` 调用，参数全是变量或回调（`e,t,n,s` / `e,function(a` …），
唯一带字符串的是 `'900 40px "PingFang SC"'` —— 那是 canvas 字体设置，**没有任何一个字符串 URL 被传给 Loader**。
Three.js 的 `TextureLoader` / `CubeTextureLoader` / `FileLoader` 只出现在导出的类清单里，属于"库自带但未使用"。

### 2.5 结论口径

> **静态证据下的强结论：零远程资源。**
> 但静态扫描不等于运行时抓包。100% 坐实请做两步复核：
> ① 断网后双击打开，能完整游玩；
> ② DevTools → Network 面板刷新，除文档本身外无任何请求。

## 3. 资源全部程序化生成（所以不需要外部文件）

这是"零远程"能成立的根本原因：**没有素材文件，素材是代码现场算出来的**。

| 资源类型 | 技术手段 | 命中 |
|---|---|---:|
| 纹理 / 铭牌文字 | `CanvasTexture` 4、`DataTexture` 10、`createElement("canvas")` 10、`fillText` 4、`getImageData` 3 | 用 canvas 画中文铭牌再当贴图 |
| 渐变与噪声 | `createLinearGradient` 6、`createRadialGradient` 11、自定义 hash/noise 函数 | — |
| 音效 | `AudioContext` 6、`createBuffer` 8、`createBufferSource` 4、`createGain` 3、`createBiquadFilter` 1 | Web Audio 合成波形，**无 mp3/wav** |
| 3D 模型 | `InstancedMesh` 19、`BoxGeometry` 6、`PlaneGeometry` 13、`CylinderGeometry` 11 | 几何体代码生成，**无 glb/gltf** |
| 第一人称手部 | `hand2*` 407 + `hand3*` 87 + `hand4*` 194 次，SDF 距离场 + 多边形化 | 程序化建模手套/袖口 |
| 多线程 | `new Blob([hand4WorkerSource()], {type:"text/javascript"})` → `URL.createObjectURL` | 最多 12 Worker 并行算帧，**Worker 源码也是内联字符串** |
| 字体 | 系统字体栈（`"PingFang SC"` 等），无 `@font-face` | 不下载字体 |

**最值得学的一招**：`hand4WorkerSource()` 把需要的函数按名字"抄一份"塞进 Blob，
因为 `src/js/` 多文件共用一个函数作用域，Worker 里拿不到 ——
这是**在单文件约束下做多线程**的漂亮解法。

## 5. 生成来源与打包方式

### 5.1 Claude 指纹（两条硬证据）

1. **`<meta name="claude:viewport-fit-sides" content="cover">`**
   这是 Claude 生成 HTML 时注入的**私有 meta 标记**，配合 `viewport-fit=cover` 处理移动端刘海/侧边安全区。
   外部资料印证：Claude Code Artifacts 会把发布文件包进 HTML 外壳，并在严格 CSP 下提供服务 ——
   **禁止外部请求、内联 CSS/JS、图片用 data URI、单页面、渲染产物 ≤ 16 MiB**。
   本文件 2.87 MB、全内联、零外链，与该规范完全吻合。

2. **CSS 首行注释**
   ```
   game/ui.css — owned by the Game agent. One deliberate dark look (a game viewport):
   port-authority signage meets a film title card.
   Sections: tokens · page + boot · HUD · radio · touch controls · menus · panel · motion preferences.
   ```
   `owned by the Game agent` 是典型的**多 Agent 分工**痕迹（Game agent 负责 UI 模块）。

> 置信度说明：meta 标记 + Agent 注释 + Artifacts 规范三者吻合，判定"Claude 生成"为中高置信度；
> 但静态文件无法 100% 排除"人工仿写"或"后期手工修改"，故不作绝对断言。

### 5.2 打包方式

| 证据 | 说明 |
|---|---|
| ESM 导出 getter 表 | `WebGLRenderer:()=>gf`、`REVISION:()=>M2`、`AudioContext:()=>mc` 等大量 `名字:()=>短变量` —— Rollup/esbuild 打包 ESM 到单作用域的典型产物 |
| 混淆标识符 | 类名/变量压成 `gf` / `M2` / `Kd` / `oi` / `en` / `Dy`；`nP` 返回玩家状态对象 |
| 中文注释保留 | 2,184 条中文注释**未被剔除**，说明是"保留注释的压缩"或生成时即如此 —— 这也是本文件可读的关键 |
| 无 source map | 未发现 `sourceMappingURL` |
| 具名函数 | 394 个长度 ≥4 的具名函数（游戏逻辑层命名保留，如 `registerGameMap` / `createSnowCoverState` / `selectGameMap`） |
| 原始工程 | 注释残留 **36 个有效模块文件名**，详见 `02-原工程架构还原.md` |

### 5.3 一句话还原

> 有人让 Claude 用一个多 Agent 分工的 `src/js/NN-*.js` 工程写了一个 Three.js FPS 游戏，
> 源码有 36 个模块、大量中文设计注释；最后用打包器 bundle + minify，

> 「零远程资源」既是设计选择，也是 Claude Artifacts 的 CSP 约束**倒逼**出来的结果。

## 6. 对本项目（网上寺庙）的直接启示

1. **单文件离线是可行的**，且已被这份作品验证到 2.87 MB 规模。
2. **"零素材"不是省钱技巧，是架构前提**：几何、贴图、音效全程序化 → 无外链 → 天然离线。寺庙题材的木石瓦纸、匾额纹样、风铃雨声同样可以全程序化。
3. **交付物单文件 ≠ 源码单文件**。原作者自己就是 36 个模块开发的，只是发布时内联。我们也应"多文件开发 + 构建内联"。
4. **不要直接改这份文件**：混淆 + 无 source map + 23.8 万字符长行 = 屎山。当规格书读，别当源码改。
5. **FPS 战斗机制整体不复用**（寺庙题材红线，见 `AGENT.md` 第 2 节），但漫游、碰撞、寻路、天气、音景、HUD 全部可借鉴。
6. **CSP 约束不是普遍真理**：若自己有服务器，完全可以用正常 CDN；只有当目标是"微信发一个文件、断网双击就能玩"时，单文件内联才是刚需。
