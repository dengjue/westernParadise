1. **先文档后代码**：每个小项动手前，先核对本节规范；规范缺失或含糊的地方，先在本文补齐定义，再写代码。

| 导出 | 类型/形状 | 说明 |

2.B3 参数解析与启动装配复用。时段/天气预设的 `label` 均引用 `COPY` 对应键，不在预设

### 2.3 时段光照预设（`timeOfDay.ts`）

```ts
export interface TimeOfDayPreset {
  readonly id: TimeOfDayId;              // 'dawn' | 'noon' | 'dusk'
  readonly label: string;                // 晨 / 午 / 暮（用户可见，走 copy 表）
  readonly sun: {
    readonly elevationDeg: number;       // 太阳仰角
    readonly azimuthDeg: number;         // 太阳方位角
    readonly colorHex: number;           // 色温意象：晨低色温暖、午白、暮橙
    readonly intensity: number;
  };
  readonly ambient: { readonly colorHex: number; readonly intensity: number };
  readonly skyTopHex: number;            // 天穹渐变两色
  readonly skyBottomHex: number;
  readonly fog: { readonly colorHex: number; readonly near: number; readonly far: number };
  readonly exposure: number;             // 色调映射曝光
}
```

三档初值取向（数值进配置，调参不动逻辑）：

| 档 | 太阳仰角/方位 | 太阳色 | 意象 |
|---|---|---|---|
| dawn 晨 | 12° / 105° | 0xffd9a0 暖金 | 低角度长影、薄雾未散 |
| noon 午 | 68° / 170° | 0xfff4e0 近白 | 顶光短影、高亮度 |
| dusk 暮 | 9° / 262° | 0xff9d5c 橙红 | 逆光剪影、暖橙天空 |

三档其余初值如下；颜色字段均为十六进制 RGB 数值，雾的 near/far 为米，曝光为无量纲值：

| 档 | 太阳强度 | 环境光（颜色 / 强度） | 天空（上 / 下） | 雾（颜色 / near / far） | 曝光 |
|---|---:|---|---|---|---:|
| dawn 晨 | 2.0 | `0xffb8a2` / 0.55 | `0x6f8194` / `0xe7c49f` | `0xb0b6b2` / 12 / 100 | 0.90 |
| noon 午 | 3.0 | `0xffffff` / 0.75 | `0x6a9bc4` / `0xdbe9ef` | `0xaebfc5` / 28 / 180 | 1.05 |
| dusk 暮 | 1.8 | `0x6f5964` / 0.50 | `0x3f4b68` / `0xd47b5e` | `0x8a6a68` / 10 / 110 | 0.90 |

### 2.4 天气预设（`weather.ts`）

```ts
export interface WeatherPreset {
  readonly id: WeatherId;                // 'clear' | 'mist'
  readonly label: string;                // 晴 / 雾
  readonly fogScale: { near: number; far: number };  // 对时段 fog 的乘数
  readonly skyTintHex: number;           // 天穹色调偏移
  readonly windStrength: number;         // 预留：M1 无粒子，字段先占位
}
```

- `clear`：fogScale {1, 1}，无色调偏移 —— 基准档。
- `mist`：near ×0.35、far ×0.45，天空偏冷灰 —— 与晨/暮叠加效果最明显。
- 字段 `windStrength` 只占位不接线，防止 M1 之后再改类型签名（阶段 3 接雨雪时直接用）。

为使“无色调偏移”具备确定实现口径，`skyTintHex` 约定为供天空颜色混合使用的中性
色调：`clear` 为 `0xffffff`，`mist` 为 `0xb8c5cc`；`windStrength` 初值分别为
`0` 与 `0.20`，M1 不消费该字段。

1. `LightingRig` 是光照唯一入口：**禁止**其它模块直接 new Light 或改 `scene.fog`；`maxLights` 由画质档位约束（low 档 ≤ 1 盏、只保留太阳方向光 + 剔除阴影）。

3. 天空穹顶、雾、曝光三处必须同帧一致，防止出现「天是暮色雾是正午」的穿帮。
4. 阴影：high/ultra 开启方向光阴影，shadow map 分辨率进 `QUALITY_PROFILES`（新增字段 `shadowMapSize`）。
5. 无 WebGL：沿用 `03-platform` 探测结果，boot 层直接走文案上屏路径，不创建 renderer。

**目标**：键鼠操控第三人称角色在庭院内自由走动、不穿墙、不掉出地面。触屏只留接口不实现。

### 5.1 产出文件

| 文件 | 内容 |

| `src/07-systems/input/KeyboardMouseInput.ts` | 键鼠实现（M1 唯一实现） |
| `src/07-systems/Character.ts` | 角色实体：程序化人形网格 + 位置/朝向/速度状态 + 每帧更新 |
| `src/07-systems/FollowCamera.ts` | 弹簧臂跟随相机：环绕角/俯仰/距离 + 阻尼；M1 不做遮挡回拉（框架第 7 节允许） |
| `src/07-systems/collision/StaticColliders.ts` | 静态碰撞盒集合（AABB 列表，来自 world 构建）+ 圆/胶囊水平投影求解 |
| `src/07-systems/index.ts` | 收敛导出 |

### 5.2 接口契约

```ts
/** 输入抽象：M1 键鼠实现，M1 后触屏摇杆并列实现，boot 按能力注入。 */
export interface InputSource {
  /** 归一化移动轴：x 左右、z 前后，模长 ≤ 1。 */
  readonly moveAxis: { x: number; z: number };
  /** 本帧视角增量（弧度）：yaw / pitch，消费后由系统清零。 */
  consumeLookDelta(): { yaw: number; pitch: number };
  /** 滚轮缩放增量，消费后清零。 */
  consumeZoomDelta(): number;
  dispose(): void;
}
```

### 5.3 行为规范

1. **移动语义**（框架第 7 节）：WASD 相对相机朝向移动；松开按键在 `accelTime/decelTime` 内平滑到零；角色朝向以 `turnSpeed` 限制平滑转向移动方向；无输入时保持朝向。
2. **鼠标视角**：按住右键（或 pointer lock，二选一实现时定稿记录在本文）水平拖 = 环绕，垂直拖 = 俯仰，钳制在 `pitchMin/Max`；滚轮调距离钳制在 `minDist/maxDist`。
3. **碰撞**：角色用水平圆（半径 = capsule.radius）对 AABB 集合求解，先整体移动再逐轴回退（先 x 后 z），实现简单且贴墙滑动自然；庭院边界用四面粉墙 AABB 处理，与「越界拉回」双保险。
4. **主循环纪律**（工程规范第 3 节）：update 内零对象分配 —— 输入增量、临时向量全部模块级复用实例。
5. **相机注视**：注视点 = 角色位置 + `headHeight`；相机位置 = 注视点 + 弹簧臂向量（含 pitch）；阻尼系数按帧长换算保持帧率无关。
6. 台基等有高差构件：M1 允许「台阶可上」，用地面高度采样（矩形台面高度表）实现，不做物理引擎。

- [ ] 可走上主殿台基、可走下，不掉出地面、不越出庭院
- [ ] 相机环绕/俯仰/缩放心感顺滑（人工验收），低帧率设备移动速度与帧率无关（逻辑步长保证）

## 7. 事件契约总表（`00-types/events.ts` 增量）

| 事件 | 载荷 | 发起方 | 消费方 |
|---|---|---|---|
| `tod:request` | `{ to: TimeOfDayId }` | UI 徽标 / URL 初始化 | boot 或系统层 |
| `tod:changed` | `{ from: TimeOfDayId; to: TimeOfDayId }` | 系统层（唯一发起） | LightingRig、SkyDome、UI |
| `weather:request` | `{ to: WeatherId }` | UI 徽标 | 系统层 |
| `weather:changed` | `{ from: WeatherId; to: WeatherId }` | 系统层 | LightingRig、SkyDome、UI |
| `guide:show` | `{ id: GuideId; title: string; body: string }` | GuideTriggers | GuidePanel |
| `guide:hide` | `{ id: GuideId }` | GuideTriggers | GuidePanel |
| `player:boundsExceeded` | `{ x: number; z: number }` | Character | Logger（仅记录，不打断） |

规则：`request` 只有一处消费方（避免双写）；`changed` 是唯一权威状态广播；guide 事件载荷带齐文案，面板层不反查配置。
