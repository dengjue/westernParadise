## 1. 原型目标和范围

在 `?cam=third` 下让玩家能从第三人称步行切换到有边界的高空观察飞行，并能读懂当前位置、朝向、所在区域和最近地标。使用现有单场景验证输入、状态、定位和安全边界，为阶段 3 的世界分区提供体验约束。

默认入口（不带 `?cam=third`）、四景点相机、第一人称漫游、音景、渲染管线、48m 分块与资源生命周期保持不变。阶段 2 的空间范围只覆盖当前 `PURE_LAND.bounds`，不把镜头远景误称为可探索区域。

## 2. 决策与控制方案

| # | 决策 | 本阶段口径 |
|---|---|---|
| W1 | 启用范围 | 飞行与第三人称角色都只在 `?cam=third` 原型模式启用；默认入口继续第一人称，避免未经体验确认改变现有默认。 |
| W2 | 模式切换 | 步行状态按 `V` 或 HUD「起飞」切入飞行；飞行状态按 `V` 或 HUD「降落」请求落地。自动游览期间不进入飞行；打开设置/手记时输入冻结。 |
| W3 | 水平飞行 | WASD 按相机 yaw 所在水平面控制前后/侧移；有界目标速度与加减速缓动，松键逐渐停止；不使用鼠标锁定。 |
| W4 | 垂直飞行 | 桌面 `E` 上升、`Q` 下降；触屏显示仅飞行态可见的「上升/下降」按住控件。滚轮仍用于跟随相机距离，不复用为飞行速度。 |
| W5 | 高度/世界边界 | 脚底高度保持在 y=42–64m；最低飞行高度高于当前已建最高构件（金色殿顶约 y=38m），避免水平飞行穿过屋顶/树冠；x/z 使用现有世界边界内缩 4m。初值来自当前几何，不代表未来扩图预算。 |
| W6 | 起飞安全 | 起飞先从角色上方检查到最低飞行高度的竖直通道；若有静态构件遮挡则拒绝起飞并提示，玩家需先走到开阔处。通过后以限速垂直爬升至最低飞行高度，不瞬移穿过建筑。 |
| W7 | 安全降落 | 降落只接受 `sampleLandHeight(x,z)` 返回有效地表的位置；飞行区下方没有可走地面时保持飞行并提示，不瞬移、不强制落到建筑/池水/边界外。阶段 2 不做远距离返航。 |
| W8 | 角色/相机 | 飞行时保留 `LandAvatar` 可见，角色脚底跟随飞行位置；第三人称弹簧臂、遮挡回拉和相机环视继续生效。 |
| W9 | 定位 HUD | 只增加低成本文本/罗盘，不做小地图：显示模式、x/y/z 米制坐标、八方位与角度、按最近区域中心判定的区域名、最近地标名和直线距离。位置文本最多 5Hz 更新；纯文本 `textContent` 更新。 |
| W10 | 眩晕/暂停 | 保留当前输入释放、失焦、弹窗和减动效路径；飞行加减速使用有界平滑，飞行状态下自动游览按钮禁用。模式变化不改变音景开关。 |

## 3. 集中配置与数据边界

- 飞行高度、世界边界内缩、水平/垂直速度、加减速、导航更新间隔、区域中心和地标坐标放入 `01-shared` 配置，不硬编码在控制循环/UI。
- 坐标统一米制世界坐标；北向约定为世界 `-Z`。heading 以北为 `0°`，顺时针递增，归一到 `[0°, 360°)`。
- 最近区域/地标按二维平面欧氏距离计算；HUD 的目标距离显示 x/z 平面距离，避免飞行高度变化造成读数忽大忽小。
- 区域、地标仅作为导航标签，不代表已完成对应区域内容，也不作为真实寺院/地理位置指引。
