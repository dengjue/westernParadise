## 2. 交互定稿（原型口径）

| # | 决策 | 内容 |
|---|---|---|
| W1 | 左键为主环视 | 左键在**画布空白区域**按下即进入拖拽环视；位移 < 4px 的轻点不产生视角增量、不吞后续点击语义（为建筑热点预留）。右键拖拽保留为兼容路径，行为不变。 |
| W2 | 第三人称角色 | 极简胶囊 + 头部（程序化、低多边形、非仪式化、非交互），脚底贴地；进入步行时出现，回到轨道机位时隐藏。命名 `LandAvatar`，不动旧 `Character`。 |
| W3 | 跟随相机 | 弹簧臂环绕角色：yaw/pitch 限制、滚轮调距、帧率无关指数阻尼；**遮挡回拉**用限频 raycast（默认 120ms 一次）缩短臂长并平滑恢复，复用向量不逐帧分配。 |
| W4 | 进入方式 | `?cam=third` URL 参数启用（与 `?quality=` 同级调试口径）；HUD 切换按钮留给阶段 2（导航信息阶段一并评审）。默认体验（第一人称 + 四景点观览）不变。 |
| W5 | 退出与暂停 | `land:suspend` / `land:modal` / 失焦 / pointer capture 归还 / `pointercancel` 全部沿用现有生命周期；退出步行（选景、自动游览接管）时角色隐藏、相机回轨道。 |
| W6 | 触屏 | `TouchInput` 的 look/移动已抽象为 `InputSource`，第三人称下同一路径生效；本阶段不新增触控布局。 |
