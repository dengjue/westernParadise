# Phase 2 · 建筑与造像近景精修

状态：已完成（2026-11-13）。前置：Phase 1（`d0256b1`）；交付分支：`feat/pure-land-phase2`。

## 目标

把当前全景构图的优势延伸到殿前、檐下和莲座近景。优先改善轮廓、连接关系、材质尺度和接触明暗，再增加小装饰。

## 实施任务

1. **结构配置化**：从 `Architecture.ts` 提取主殿、亭阁、塔和柱础参数，区分结构骨架与可降级装饰；与导航表面共享尺寸来源。
2. **屋面构造**：梳理脊线交接、檐口厚度、瓦当、滴水和屋面分段；檐角连续，避免金线相交处穿插或悬空。
3. **檐下细节**：斗拱承接关系、梁枋接头、柱础压边、格窗深度；构件投影在近看时可读。
4. **铺装与台基**：石缝尺度统一，阶梯边缘有倒角，金属嵌条保持克制；法线/粗糙度细节优先于大量细碎几何。
5. **造像精修**：调整面部比例、手部衔接、衣褶厚薄和莲座花瓣，消除明显球体拼接感；静态造像的视觉焦点集中在整体姿态。
6. **材质分工**：石、玉、木、金、瓦分别校准粗糙度、色阶与纹理密度，避免金属像塑料、石材像发光面。

## 工程与性能

- 资产生成器接受明确细节级别，为 Phase 4 的近/中/远 LOD 预留稳定接口。
- 保留索引、共享可复用原型；重复构件优先实例化或按空间/材质合批。
- 每类新增细节先记录单个资产顶点/三角形/缓冲字节，再更新全场基准。
- 初始预算：high 的近景新增提交三角形不超过 P1 同机位的 20%；超过预算时先将次级细节转入材质或距离分级，再纳入全场。

## 本轮实施拆解

1. 新增共享建筑/工艺配置，集中主殿、台阶、柱列、亭阁和三档构件细节。台阶起止位置、平台高度、柱础半径由建模与导航共用。
2. 抽离连续屋面生成器，补上檐口厚度、檐下椽条、筒瓦端面纹饰与脊线收口；细节档位控制采样与装饰密度。
3. 主殿增加带倒角的石台阶、柱础轮廓、檐下雀替、梁枋纹饰和格窗边框，消除薄面和盒体直接相交的近景问题。
4. 造像使用连续轮廓与有起伏的衣料曲面，面部细节贴合头部表面；手臂采用渐变截面，衣褶从形体中生长，莲座与底座衔接完整。
5. 区分结构石材/雕刻石材，协调颜色、凹凸和粗糙度的纹理尺度，校准木、瓦、玉、金的反光特性。
6. 固定殿前、檐下、柱础、莲座四个检查机位，保存基线与最终截图；运行 high/low 四景点基准和几何预算回归。

新增细节以主殿与近处亭阁为重点，远景沿用简化等级。high 每帧提交三角形仍执行相对 P1 不超过 +20% 的预算；结构/装饰配置与资产级预算随阶段结果入库。

## 实施结果

### 结构与材质

- **屋面**：`Roof.ts` 独立生成坡面、檐口侧面、木质底面、椽条、四条垂脊和筒瓦端面。修复旧版垂脊重复同一角点、遗漏其他角点的问题；瓦当由高面数球体换成低面数筒体与莲瓣纹饰。
- **檐下**：增加雀替、梁枋卷草纹、双层窗框和细压边；柱础用方形倒角底座、束腰与承盘轮廓承接柱身。
- **台基**：原正殿整片金属盖板与石地面同高，近景出现强烈闪烁；现压边只沿台基侧面，顶层是一块完整石面。阶道后缘与 3.2 米台面接平，修复旧版平台实际高度和导航高度不一致。
- **造像**：连续椭圆截面重建衣料、膝部与头部，鼻梁/眼窝/嘴唇直接构成表面起伏，领缘沿衣料表面铺设。袖管由肩部内部逐渐收束到手掌，双层有厚度的莲瓣包围束腰底座。
- **材质**：雕刻石材与铺装分离；石材颜色、凹凸、粗糙度共用世界坐标投影，柱础不再带铺装砖缝。调整金、木、瓦、玉的粗糙度与金属度。

## 性能结果

基线为保存的 Phase 1 生产 HTML。本轮在同一浏览器中按 high 前/后、low 前/后顺序重新采样：Tabbit / Chromium 156，1601 × 997 CSS 像素、DPR 2、seed=20261113、落照、正常动效。每景点预热 60 帧并采样 180 帧；high 渲染比率 1.5，low 为 1。

| 指标 | high P1 → P2 | low P1 → P2 |
|---|---|---|
| 静态几何缓冲 | 37,256,028 → 37,323,452 字节（**+0.18%**） | 36,284,572 → 32,411,452 字节（**-10.67%**） |
| 静态缓冲 MiB | 35.53 → 35.59 | 34.60 → 30.91 |
| 静态三角形 | 1,056,246 → 1,027,046 | 1,025,974 → 864,774 |
| 全景每帧提交三角形 | 3,299,628 → 3,241,228（**-1.77%**） | 2,504,974 → 2,182,574（**-12.87%**） |
| 全景每帧 draw calls | 55 → 61 | 41 → 47 |
| 纹理对象计数 | 26 → 31 | 11 → 16 |

其余景点的三角形变化一致，主殿景点比表中各少 2 个提交三角形、1 个 call。新增雕刻石材、瓦当与梁枋材质形成三个批次，主视图加反射共增加 6 calls；颜色/数据贴图与纹饰合计增加 5 个纹理对象。high 的新增衣料与莲瓣顶点抵消了瓦当减负，缓冲基本持平；low 同时降低屋面采样、筒瓦密度和造像细分，获得更明显减负。

| p95 帧间隔（ms） | 全境 | 莲池 | 宝殿 | 宝林 |
|---|---|---|---|---|
| high P1 → P2 | 16.8 → 16.7 | 16.8 → 16.7 | 10.3 → 10.2 | 16.3 → 9.1 |
| low P1 → P2 | 9.0 → 10.4 | 16.8 → 25.0 | 9.8 → 9.8 | 16.7 → 16.6 |

p50 均约 8.3ms。单轮帧间隔存在系统调度波动，low 莲池的 p95 回退如实保留；以上不构成 GPU 加速或真实手机帧率结论。缓冲数据为有效几何数组字节，不是总显存。所有固定景点满足本阶段 +20% 提交三角形上限。
