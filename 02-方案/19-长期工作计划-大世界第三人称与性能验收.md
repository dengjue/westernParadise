## 1. 愿景和不变约束

### 目标体验

1. 游客始终能知道**当前位置、朝向、所在区域和目标地标**；可步行探索，也可切换飞行自由观察。
2. 采用第三人称角色及跟随镜头；桌面主要在场景画布上用**鼠标左键拖动控制环顾方向**，而非右键。键盘负责移动/升降，滚轮调整镜头距离；触控保留双指环顾和现有移动控件。UI、说明面板和可交互物上的点击不应被误认成镜头拖动。
3. 世界在体验上显著扩大，但不要求一次性把全世界几何、纹理和渲染对象放进显存/内存。近处精细、远处低成本，离开视野的区域可卸载或只保留轻量表示。
4. “加载有限素材”优先解释为**有限的、可审计的素材种类与同时驻留预算**：沿用程序化、共享材质/几何、实例化和本地分块生成；不依赖在线 CDN、账号、服务端或运行时外网。若将来引入独立美术资源，必须仍能打包进离线单文件并通过零外链验收。

### 不变红线

- 继续定位为传统建筑与园林空间的数字展示/文化漫游；不增加战斗、排行、交易、募捐或仪式交互。
- 继续支持离线单 HTML、四档画质、减动效、键鼠/触控、声音和资源正确释放；不得以降档、删景、弱化建筑近景质量掩盖性能问题。
- 大世界采用有边界、可分块、可测试的空间，不把“世界大”实现成无限生成或没有导航目标的空旷扩图。
- 所有性能判断绑定实际产物、设备、视口、画质、行走/飞行路线及采样口径；诊断探针数据不得替代轻量生产验收。
- 每阶段先写假设和验收，再动实现；一次验证一个主要变量，失败样本及回滚理由保留。

## 4. 交互与技术专题清单

以下为规划检查项，不代表已经选型或实施。

### 左键环视与第三人称

- 将左键拖拽限定在 3D 画布空白区域；点击 UI、建筑热点或 HUD 不启动环视。明确点击阈值，避免轻点被吞成拖动。
- 拖动期间使用 Pointer Events / capture；指针离开画布仍能正确结束。窗口失焦、切 tab、弹窗和取消操作必须归还 pointer capture、按键状态与光标状态。
- 评估普通捕获、pointer lock 与触屏行为；默认优先不锁定系统指针，只有原型证明需要连续转向时再把 pointer lock 作为可选方案。避免未经用户触发就锁鼠标。
- 相机围绕角色而不是替代角色；以弹簧臂/遮挡回拉控制穿墙，第三人称镜头自身单独做碰撞。镜头方向和角色移动方向规则必须明示且可验证。
- 右键不再是主方向控制；右键浏览器菜单的处理范围、上下文菜单可访问性和键盘替代操作在交互规范阶段决定，不能粗暴屏蔽全页面右键。

### 飞行与定位

- 飞行是观察空间的移动模式，不引入战斗/任务化系统。规划平滑加速、减速、最大速度、垂直控制、低速悬停、碰撞/禁飞边界、起降点和失焦暂停。
- 空中视角容易失去尺度；以地标、区域名、朝向刻度/罗盘、返航/回到地面入口支撑定向。地图/小地图先做低成本 UI 原型，避免默认常驻的大纹理/高更新开销。
- 需要评审是否允许任意飞越屋顶、进入建筑内部或越出世界边界；默认方案是有限边界、重点区域安全飞行、不可访问体积有明确阻挡/提示，细节待用户确认。

### “世界很大”与有限素材

- 先定义可玩面积、典型步行/飞行总时长、地标密度和区域间距，再换算空间尺寸；仅扩大世界坐标会让空间空洞、游览无目标。
- chunk 以已有 48m 方案作基线候选而非固定答案。通过区域密度、LOD 切换、视距和 CPU/GPU/内存实测评估更大区块或分层区块；避免每个小区块产生过多 draw calls。
- 资源分层：共享基础材质/贴图和程序化模块；活动近区保留完整资产和碰撞；中区采用低细节/实例批次；远区仅保留地标轮廓；离开活动区后释放临时资源。音景、阴影、反射和后处理都纳入相同的空间预算。
- 离线单文件方案优先使用随产物打包的区域描述/程序化 seed，按需生成/启用场景块；不得让“流式加载”隐含网络请求。离线读取压缩/内嵌二进制资源的成本与浏览器限制要单独原型验证。
- 建立上限与回稳指标：活动 chunk 数、生成/释放队列、几何/纹理/programs、缓冲字节、draw calls、提交三角形、峰值驻留、跨区生成耗时、低端机温升/掉帧。哪些指标能从浏览器取得要标可观测/不可观测，不以估算冒充真实显存。

## 5. 验收办法与风险门

每个候选采用“固定路线与机位 + 可见性/功能检查 + 轻量性能样本 + 诊断样本（如必要）+ 资源往返 + 离线回归”。最低矩阵：

| 维度 | 需要覆盖 |
|---|---|
| 模式 | 第三人称步行、第三人称飞行、切换、自动游览/手动接管、暂停/恢复 |
| 输入 | 左键拖动/点击、键鼠移动、滚轮、失焦恢复、触控双指、UI 操作冲突 |
| 空间 | 起始区域、相邻 chunk 边界、远距离地标、快速转向、快速飞行、返回已卸载区域 |
| 视觉 | 四个现有重点视点、建筑近景、地平线/远景、区域过渡、昼/暮/晨、主要画质档 |
| 运行 | 目标桌面与实际手机；冷启/预热；短路线与持续负载；离线无外链；资源卸载后回稳 |
| 生命周期 | 后台/锁屏、BFCache 原生往返（由 C0 设备/通道解除后执行）、WebGL 丢失或无法创建的兜底 |

风险门：第三人称导致遮挡/构图下降则先调整相机，不牺牲建筑质量；大地图导致空洞则先调整区域内容密度而非盲目增面积；飞行导致加载追不上则调度预取/速度/区域边界并报告体验代价；资源不回稳则不扩大内容规模；离线单文件做不到时必须先提出交付形态变更并获用户明确确认，不私自引入网络依赖。
