# 西方极乐 · 六阶段交付与操作索引

日期：2026-11-13。当前完整源码在 `feat/pure-land-phase6`；默认体验为四景点观览与第一人称游历，历史第三人称庭院仍可访问。六阶段实现、本机功能、离线与 30 分钟桌面持续运行验收已完成；真机、原生后台与严格无长帧验收仍开放。

## 1. 打开与复现

```bash
npm ci
npm run verify
```

- **离线入口**：双击 `dist/single/index.html`，包含所有程序化建筑、材质、自然声与 Three.js 运行时。
- **开发入口**：`npm run dev`，访问终端打印的地址。
- **固定画质/光阴**：`?q=high&tod=dusk&seed=20261113`；四档为 low / medium / high / ultra，光阴为 dawn / noon / dusk。
- **历史庭院**：`?scene=courtyard`；与默认极乐世界的控制和画面不同。
- **静音链接**：加 `&noaudio`。默认入口本就关闭声音，只有主动开启才创建音频图。
- **诊断入口**：加 `&bench` 或 `&debug` 才暴露 `window.__G`；普通体验链接保持精简。

精确体积/MD5 以 `reports/single-build.json` 为准；本轮离线与长测报告还记录 SHA-256，便于确认测的是同一 HTML。`dist/` 与 `reports/` 是本机可复现产物，按规范不入 Git；源码、锁文件、实施结论和复跑脚本入库。

## 2. 操作说明

| 操作 | 效果 |
|---|---|
| 顶部四景点 / 左上标识 | 切换预设构图，退出自动游览或步行；标识返回全境 |
| 步入此境 | 从中轴入口进入步行；重复点击不重置当前位置 |
| WASD / 方向键 | 步行；在观景模式输入时从附近安全通路进入 |
| 右键拖动 | 环顾；自动游览中从当前可见机位接管 |
| 滚轮 | 观景模式拉近/拉远；自动游览中手动接管 |
| 自动游览 / 暂停游览 | 四景点循环，10 秒停留 + 10 秒曲线行进；暂停后沿原进度续走 |
| 晨光 / 晴昼 / 落照 | 3.2 秒平滑切换，可中途重定向；减动效下立即完成 |
| ♫ / 音量 | 默认静音；开启风、水、鸟、檐铃和脚步的区域自然声，音量初始 60% |
| 手机左区 / 右区 | 左侧移动、右侧环顾，支持双指，松手/取消即停止 |
| ☷（窄屏/短屏） | 展开画质与音量设置，暂停镜头、隐藏触控区；Escape 关闭 |
| 造境手记 | 查看设计来源，打开时清空输入并暂停镜头；Escape 或 × 关闭 |
| H / 隐藏界面 | 隐藏后仍保留「显示界面 · H」按钮；Escape 也可恢复 |
| 画质 | 重载为所选档位并保留当前光阴；几何布局保持相同，密度/反射/阴影按档位变化 |

步行眼高 1.7 米，中央阶道与两侧亭廊可通行；池水、柱础、格窗、墙、栏杆和造像底座为实体边界。浏览器关闭/重载后从预设机位重新开始，当前游览位置不作为存档保存。

## 4. 验收和性能边界

### 已通过

- `npm run verify`：24 个测试文件 / 135 用例，类型、分层、内容、lint、格式、双构建、单文件离线断言。
- 最终 HTML `file://` 禁网实玩：远程请求/运行错误均为 0，走入殿内、游览暂停续走、右拖接管、声音与界面操作正常。
- 四档 UI 重载、四种触控布局、双指移动/环顾、说明/设置冻结、减动效画面冻结与即时换光阴。
- 四次真实装配/释放：396 几何、37 纹理、1 canvas、21 跟踪监听器最终归零；上下文丢失后不误恢复绘制。
- 无 WebGL 可见提示和重载入口；历史庭院正常。
- **30 分钟可见桌面混合长测**：209,446 绘制帧，隐藏/暂停/错误均为 0；首段上传后保持 524 几何 / 37 纹理 / 25 programs，环境烘焙维持 3。单段 p95 桶上界 10–17ms、最大 41.8ms；粗粒度 JS 堆从 97.4 MB 阶跃到 103 MB 后持平，详见 Phase 6 的逐段记录。

### 待完成的实际验收

执行顺序、分步任务与完成标准已写入 [后续优化方案](18-后续优化-性能收敛与真机验收.md)；当前步骤与逐项状态见 [AGENT_TODO.md](../AGENT_TODO.md) 的后续优化执行队列。

- **长帧**：high 光阴过渡 p95 25.0–33.4ms、最大 150ms；未满足严格无长帧目标。CPU profiler 在当前工具不可用，保留 Long Tasks 与退化样本，未确认 GC/驱动归因。
- **真实手机**：low/medium 的持续 30 FPS、发热后性能、内存和安全区；目前移动数据是桌面触控模拟。
- **原生生命周期**：真实切后台、锁屏和 BFCache 返回；事件模拟已通过，但浏览器工具的前台保留策略和 BFCache 限制使原生路径仍待人工验证。

稳态短测与完整游览/光阴过渡是不同负载；帧间隔、CPU 提交时间、GPU 查询时间也是不同指标。当前数据不支持「所有设备稳定 60 FPS」或「无卡顿」的说法。

## 5. 证据与维护入口

| 入口 | 用途 |
|---|---|
| `scripts/benchmark-pure-land.mjs` | 四景点稳态帧间隔、CPU/GPU、更新/缓存帧与资源预算 |
| `scripts/verify-land-lighting.mjs` | 完整/中断光阴、缓存身份、反射预算及过渡长帧 |
| `scripts/verify-land-render.mjs` | 快速切景、独立 LOD、资源回稳与四次真实重挂 |
| `scripts/verify-land-journey.mjs` | 真正键鼠输入、弹窗冻结、台阶、游览与音频 |
| `scripts/run-land-soak.mjs` | 通过 Tabbit 执行 12×150 秒可见长测，输出 `reports/phase6-soak.json` |
| `src/01-shared/land{Craft,Layout,Journey,Sound}.ts` | 建筑、导航、曲线路线、眼高速度与声景参数 |
| `tests/land{Navigation,Journey,Builder}.test.ts` | 通路往返、碰撞扫掠、暂停接管与曲线缓存等价性 |

长测应保持预览可见且活动，记录具体机器、浏览器、CSS 尺寸、DPR、画质和产物散列；隐藏时间或暂停帧大于 0 的样本不能当作完整持续负载通过。不要加速逻辑时间冒充真实运行时长。
