# Phase 3 · 莲池与宝林自然细节

状态：待实施。前置：Phase 1，沿用 Phase 2 的资产预算口径。

## 目标

维持七重行树的秩序与四色莲花的意象，让近景有生长差异、轻微动态和自然水岸关系。

## 实施任务

1. **随机流拆分**：树木骨架、树叶、莲花布局和装饰各有独立 seed；按对象稳定 ID 派生随机数。切换画质后，树高、花心和主枝位置保持一致。
2. **树冠层次**：树冠外轮廓、枝叶密度、朝向和色差做有限变体，冠内保留透光缝隙；减少当前均匀撒叶的球状感。
3. **宝叶与珠网**：叶脉、叶缘弯曲、枝梢与珠线连接可读；珠饰使用合理的中远景细节级别。
4. **莲花与莲叶**：开放程度、瓣数和花高做稳定变体；莲叶有弯边、叶脉和轻微起伏，花朵与叶片避让台基和池岸。
5. **轻风动效**：实例属性储存摆幅、相位和枝端权重，在 GPU 中运行；树干和台基固定，减动效模式归零。
6. **水面关系**：校准莲花浮高、池边倒影和涟漪尺度；强高光区域仍看得见莲花与池岸轮廓。

## 工程与性能

- 几何/材质变体数量有上限，变体共享资源；每帧不重写全体实例矩阵。
- 动态包围体包含最大摆幅，主视图与反射使用同一动画时间。
- 风动与静态阴影的冲突须明确处理：选择动态叶片阴影预算或近景阴影代理。
- low 保留同一布局和主要花形，按稳定子集抽样细叶与次级花瓣。

## 验收

- [ ] 同 seed 的 high/low 树干与花心位置一致；切档不改变世界布局。
- [ ] 固定种子可复现；不同种子变化合理且不侵入通道。
- [ ] 近景叶片不闪烁、花叶不明显穿插，风动没有同步机械摇摆。
- [ ] 减动效下风与水面动画停止，触控和自动游览正常。
- [ ] 四景点性能与内存报告、`npm run verify`、离线检查通过。
