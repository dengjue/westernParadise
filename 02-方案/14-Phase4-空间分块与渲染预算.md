# Phase 4 · 空间分块与渲染预算

状态：待实施。前置：Phase 1–3 已形成代表性资产与采样基线。

## 目标

使近景只承担必要的几何与反射工作，让 low 与 high 的成本差异体现到建筑、植被和像素处理全过程。

## 实施任务

1. **空间分块**：静态建筑按区块及材质合批，宝林/莲池实例按池区分组；比较 24/48 米等候选粒度，以实际收益选择。
2. **距离分级**：近景保留瓦当、衣褶、珠饰，中景保轮廓与主要脊线，远景简化构造；采用滞回阈值避免边界来回切换。
3. **反射分级**：单独控制反射可见层与几何细节；静止时限频，镜头/光阴改变时及时失效，避免缓存倒影跟不上镜头。
4. **反射正确性**：主相机与反射相机分别评估可见性；水纹时间持续推进，缓存只减少场景重绘。
5. **后期预算**：检测实际渲染尺寸、MSAA、HDR 目标和泛光 mip 的成本；手机优先控制像素填充率，再决定是否保留后期。
6. **自适应策略**：使用连续超预算区间与恢复滞回调整分辨率/反射，尊重用户手动固定画质；避免每几帧切档造成视觉呼吸。
7. **资源生命周期**：区块/LOD/反射目标的归属明确，共享几何去重释放，重复挂载和画质切换后资源计数回稳。

## 预算与取舍

- 分块增加 draw calls，但应减少近景提交三角形与不可见像素；同时衡量两项，不能只优化一个数字。
- 目标：代表近景的提交三角形减少至少 30%；全景 p95 无持续回退；low 在目标手机达到 30 FPS 档位目标。
- CPU 提交时间、帧间隔、GPU 时间分开记录；GPU 计时扩展不可用时明确缺项。
- 反射更新率由实验确定，测试静止、快速转头、光阴切换和水岸斜视四类场景。

## 验收

- [ ] 四机位与步行路径无区块消失、LOD 裂缝或明显突变。
- [ ] 反射不漏建筑，移动镜头无长时间错位倒影。
- [ ] 同设备同视口的 high/low/移动对比报告完整。
- [ ] 长时间循环景点和切换画质后，无持续增长的资源或监听器。
- [ ] 工程门禁、离线和降级路径均通过。

主要变更：`Builder.ts` 分块、资产 LOD、`Atmosphere.ts`、`CinematicPipeline.ts`、quality 配置和诊断层。完成后记录选定阈值与被否决方案。

## Phase 3 交接基线（2026-11-13）

- high / low 全景提交三角形：3,487,100 / 2,187,118；draw calls：63 / 47。
- 静态合批缓冲：38,538,684 / 33,149,884 字节；实例缓冲：1,675,944 / 823,584 字节，含风动属性。
- 稳定布局为 28 棵树、144 个花心、288 片莲叶；分块与 LOD 应沿用对象 ID 和叶片前缀子集，保持切档不漂移。
- high/ultra 的 280 个静态冠团阴影代理仍在主视图与反射各提交一次，可纳入独立层治理；所有植物包围体须保留风动余量。
- high 全境 p95 帧间隔由 16.7 增至 25.2ms，作为优先复测项；帧间隔并非 GPU 时间，移动端现阶段仅通过触控模拟。详细采样口径与证据见 Phase 3 文档。
