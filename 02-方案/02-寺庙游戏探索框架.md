## 1. 边界定稿

参考件是一个 FPS（射击、敌人、波次、撤离）。**这套玩法机制整体不适用于本项目**：
把宗教场所做成战斗场景、把圣像或宗教人物做成敌人/目标，既不尊重，也踩合规红线。

本项目复用的是它的**技术外壳**（离线单文件、程序化场景、天气音景、漫游碰撞、HUD），
**内容内核重新设计**。一句话定位（已定稿）：

> 「一个可离线漫游的**传统建筑与园林空间**数字展示：看光影、听风雨、读建筑、慢慢走。」
> 关键词：**文化空间 / 建筑美学 / 静观氛围**，不是宗教活动、不是游戏闯关。

明确不做的机制（与 `AGENT.md` 第 2 节、`check:content` 门禁一致）：
仪式模拟（上香/跪拜/诵经/敲钟祈福等）、功德募捐与付费祈福、讲经讲道与经文文案、
以宗教人物/圣像为角色或交互对象、排行/战力/抽卡等强游戏化、真实寺院名称与僧团肖像。

## 3. 场景设计草案（纯空间，不含宗教内容）

```
                    远景：山影 / 林线 / 云
   ┌──────────────────────────────────────────────┐
   │  照壁（纹样，程序化生成）                      │
   │      ┌──────── 前庭 ────────┐                │
   │      │  铺装 / 苔痕 / 积水    │   侧院：竹、石  │
   │      │   · 光影随时间移动     │                │
   │      ├──── 台基 + 阶道 ─────┤                │
   │      │  柱列 / 檐廊（可穿行） │   回廊 → 二层   │
   │      │  格扇 / 藻井意象       │                │
   │      └──────────────────────┘                │
   │  后院：水面、石桥、落叶                        │
   └──────────────────────────────────────────────┘
```

| 层 | 内容 | 技术手段（全部程序化，无外部素材） |
|---|---|---|
| 结构 | 台基、阶道、柱列、檐廊、格扇、屋面 | `BoxGeometry` / `CylinderGeometry` / `InstancedMesh` 参数化批量 |
| 材质 | 木、石、瓦、纸、苔、水 | `CanvasTexture` 画纹样、`DataTexture` 噪声、渐变 |
| 光影 | 晨昏色温、檐下阴影、体积光、雾 | 光照配置 + 天空变体 + 条件编译 shader |
| 天气 | 雨、雪、落叶、风 | 粒子 + 材质补丁（参考 `SL_SNOW` 思路） |
| 音景 | 风、雨、檐铃、脚步、远处环境声 | Web Audio `createBuffer` 合成，**无诵经/法会音** |
| 文字 | 建筑构件说明、方位提示 | canvas `fillText` 生成贴图；文案逐条审查 |

## 5. 决策记录（2026-11-12，用户拍板）

| # | 决策项 | 定稿 | 说明 |
|---|---|---|---|
| D1 | 题材边界 | **按红线文档建议定稿**：文化空间 / 建筑美学 / 静观漫游 | 不做仪式、经文、募捐、战斗、真实寺名；探索期不上线不外发 |
| D2 | 玩法主线 | **① 自由漫游 + 光影时序为主线，② 建筑导览为辅线**，④ 作氛围底座 | M1 只做①的最小闭环 + 辅线的说明面板 |
| D3 | 视角 | **第三人称**（未取推荐的第一人称） | 需角色实体 + 跟随相机，技术影响见第 7 节 |
| D4 | 文字尺度 | **M1 即加入建筑知识说明**（未取推荐的 M1 无文字） | 文案集中 `copy.ts`，逐条过 `check:content` + 人工审查 |

**执行口径**（随 D2~D4 一并生效的默认值，非终局决策，后续可改）：

| 项 | 口径 | 理由 |
|---|---|---|
| 时段推进 | 固定时段 + 手动切换（晨 / 午 / 暮） | 最简可控；实时流逝留到 M1 之后评估 |
| 场景规模 | 单个庭院闭环 | M1 目标是跑通链路，多进院落留到后续 |
| 美术调性 | 程序化写意、低饱和，具体 M1 出效果后再校 | 避免过早锁定风格返工 |
| 移动端 | M1 键鼠优先；触屏摇杆在输入抽象层就绪后接入（2.B4） | 输入层一次做多源适配，但 M1 只验收键鼠 |

## 6. M1 验收定稿

- [ ] 断网双击 `dist/single/index.html` 可运行，DevTools Network 无外部请求
- [ ] 一个庭院场景；**第三人称角色**键鼠可自由走动、不穿墙、不掉出地面
- [ ] 至少 3 个时段光影明显不同（晨 / 午 / 暮），可手动切换
- [ ] 一项天气效果（雨或雾）可切换
- [ ] 走到台基 / 柱列 / 屋檐等构件附近弹出**建筑知识说明**（≥ 4 条，全部过红线审查）
- [ ] 无任何仪式、经文、募捐、战斗元素（`check:content` + 人工双确认）
- [ ] `src/` 分层清晰、配置与逻辑分离、关键算法有中文注释
- [ ] 单文件体积 ≤ 2.87 MB（参考件实测值）

## 7. 技术影响（由 D3 / D4 带来的增量）

**第三人称（D3）**

| 增量 | 说明 |
|---|---|
| 角色实体 | 程序化极简人形：胶囊身体 + 头部几何，无面部细节、无服饰贴图；中性配色 |
| 跟随相机 | 阻尼弹簧臂跟随；鼠标控制环绕角与俯仰，滚轮调距离；相机穿墙需做遮挡回拉（M1 可先简化为不检测） |
| 移动语义 | WASD 相对相机朝向移动，角色朝向平滑转向移动方向；加速/减速曲线进 `01-shared` 配置 |
| 碰撞 | 参考件的「相机即身体」改为角色胶囊与场景碰撞盒求交；碰撞数据结构直接复用 |
| 分层落点 | 角色与输入在 `07-systems`（编号已预留）；相机策略在 `04-engine` 或 `07-systems`，实现时定 |

**建筑说明（D4）**

| 增量 | 说明 |
|---|---|
| 触发 | 靠近构件 → `07-systems` 距离检测 → 事件总线 `guide:show` / `guide:hide` |
| UI | `08-ui` 说明面板（标题 + 正文），复用参考件 HUD token；不做弹窗打断漫游 |
| 文案 | 集中 `01-shared/copy.ts`，M1 ≥ 4 条（台基、柱列、屋檐、铺装起步）；每条过 `check:content` + 人工审查 |
| 标记 | 构件上方可选挂 world-space 提示标记；M1 先做纯距离触发，标记后补 |

**对里程碑排序的影响**：2.B4（角色与输入）和 2.B5（说明面板）从「可延后」升级为 **M1 必选项**，
且 2.B4 需要先定输入抽象层 `InputSource` 接口（键鼠先行，触屏复用同一接口）。
