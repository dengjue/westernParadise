# 精修大世界联机交付备忘录

主体验是第三人称极乐世界，旧庭院仅作协议对照。按以下顺序推进，区分程序验证与真机验收。

1. [ ] 固化 qu3 已部署的局域网底座与已验证的跟随镜头修改。
2. [ ] 地面联机：独立房间、主场景坐标与地面校验；双方从入口出现，复用角色渲染，离开步行或断网清除远端角色。入口 `/?cam=third&multiplayer=1`。
3. [ ] 部署 qu3，验证两个客户端的入场、移动、视野进出与断开；再做手机/电脑并肩走查，记录镜头稳定性。
4. [ ] 地面验收后扩展飞行同步：高度、速度、升降状态与空地混合画面。
5. [ ] 分散与聚集各压测 2、10、30 人，依据实测带宽、节拍、CPU 和帧率决定容量。

每个阶段保留可复现的检查、提交和推送记录；离线与普通单机入口不主动联网。
