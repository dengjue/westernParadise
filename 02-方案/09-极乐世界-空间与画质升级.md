# 极乐世界 · 空间与画质升级

2026-11-13，依据本轮用户指令：以《阿弥陀经》《观无量寿经》为视觉研究依据，制作精美、可进入游览的寺庙世界；画质参照 `00-原文件/几猫国产3A大作2.html`。

## 美术与技术

- 金白、孔雀青、暖木色为主体，珠宝色只作点缀。轮廓、空间构图先于发光特效。
- 重檐曲面屋顶、檐口金线、瓦垄、柱础、斗拱、格窗、莲瓣、珠网均为三维构件。
- 金属及白石使用程序化细纹，环境反射、定向软阴影、水面平面反射、克制的 HDR 泛光共同建立材质区别。
- 近景莲池—中景宝殿—远景楼阁形成纵深；初始镜头可直接看到全景，可切换四个观景点与步行模式。
- 支持晨光、日间、落照，环境音开关、自动游览、隐藏界面、画质选择与触控。
- 按已有单向分层组织新增模块；程序化构件合批、实例化叶片与花瓣，保持离线双构建。

## 验收

- 工程：`npm run verify`。
- 浏览器：检查首屏、近景莲池、殿前、时段切换、漫游与触控，检查错误与实际绘制性能。
- 离线：重新构建单 HTML，`file://` 打开检查无外部资源请求。

## 验收结果 · 2026-11-13

- `npm run verify` 通过：类型、分层、内容、格式、ESLint、16 个测试文件 / 88 用例、两种构建与单文件检查。
- 最终单文件 723,102 字节；机器报告见 `reports/single-build.json`。
- Tabbit 中以 `file://` 加载最终文件，并启用 CDP 离线网络条件：正常渲染，HTTP(S) 请求 0，脚本/控制台错误 0。
- 桌面实测：四景点、三时段、进入步行后键盘移动、全景与步行右键拖动及松手停止、滚轮缩放、自动游览暂停、手记开关、H 隐藏恢复、音频启停、high/ultra 切换与时段保留。
- 390 × 844 触控模拟：页面无水平溢出，CDP 触摸拖动使角色实际移动；low 档正常渲染。
- 减动效：水面动画时间为 0，并显示提示；禁用 WebGL 后出现明确错误与重载入口。
- 静态合批与实例化后，high 实测全帧绘制约 55 次（含水面反射与后期）；一轮桌面 60 帧采样约 120 FPS。该帧率只代表当前浏览器设备，不外推至其他硬件。
